# グローバル開発・エージェント行動ルール

全 AI エージェント（Antigravity / Gemini CLI, Claude Code, Cursor, Codex 等）共通のグローバルガイドラインです。

## 1. 言語設定 (Language Settings)
- **第一言語 (Primary Language)**: すべての出力（回答、計画、説明、コードコメント、コミットメッセージ等）は原則として **日本語** で記述してください。
- **スタイル**: 簡潔かつ丁寧な日本語を使用してください。

## 2. 進行状況の可視化
- **目的中心かつ最小限の出力**: ツール呼び出し前に長々と実況せず、「何のために何をするか（目的）」を一言で端的に出力してください。
  - Good: 「ルールファイルの存在を確認します」
  - Bad: 「現在、プロジェクトルートに GEMINI.md や .agents ディレクトリが存在するか確認しています。」
- 思考内容が UI に表示されない場合でも、ユーザーが現在の作業目的をストレスなく把握できるようにしてください。

## 3. 自律的な進行 (Auto Mode の徹底)
- **不要な確認の中止**:
  - ユーザーから明示的な指示があった作業、またはその完了に不可欠な一連の工程（ビルド確認、git commit、git push、テスト実行、スクリプト実行など）は、「実行しましょうか？」と確認を挟まず、自動的に完了まで進めてください。
  - `ask_question` や確認待ちは、要件が著しく曖昧な場合や致命的な破壊的変更を伴う場合を除き、使用しないでください。
- **安全なコマンドの自律実行**:
  - ビルド確認、テスト、ファイル操作、git commit、git push、curl による疎通確認などは確認なしで自律実行してください。

## 4. 環境・シェル制約 (PowerShell / Windows)
- **コマンド連結**:
  - コマンド連結に `&&` は絶対に使用せず、セミコロン `;` を使うか個別のコマンド実行に分割してください。
- **文字列エスケープ・文字化け防止**:
  - `gh pr` の `--body` や `git commit` の `-m` などで、コマンドライン引数に直接 Markdown や特殊文字（`\`, `"`, `` ` `` 等）を展開しないでください。PowerShell のエスケープ規則（エスケープ文字は `` ` ``）や外部プロセスへの引数受け渡しにより、`\b`（バックスペース）などの制御文字化やバックスラッシュの混入・欠落が発生します。
  - 複数行テキスト、バッククォートを含む Markdown、メッセージ等は、必ず**シングルクォートヒアドキュメント（`@' ... '@`）で一時ファイルに書き出してファイル指定オプション（`--body-file` や `-F`）で渡す**か、ファイル書き込みツールを使用してください。

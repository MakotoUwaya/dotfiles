# Humanizer-JA

日本語の AI 生成文から「AIっぽさ」を除去する Claude Code スキル。

経営会議報告・週次報告・社内ドキュメントなど、ビジネス文書での利用を想定。LLM が生成する日本語特有の不自然なパターン 30 種を検出し、人間が書いたと違和感のない文章に仕上げる。

[blader/humanizer](https://github.com/blader/humanizer) の構造を参考に、日本語ビジネス文書向けに再設計。

## インストール

```bash
mkdir -p ~/.claude/skills/humanizer-ja
cp SKILL.md ~/.claude/skills/humanizer-ja/
```

## 使い方

Claude Code で：

```
/humanizer-ja

[テキストを貼り付け]
```

または：

```
この文章を humanize して：[テキスト]
```

## 検出する 30 パターン

### 内容パターン（1–8）

| # | パターン | 典型例 |
|---|---------|--------|
| 1 | 重要性の水増し | 「極めて重要な役割を果たしており」 |
| 2 | 抽象的な成果報告 | 「順調に推移」「着実に進捗」 |
| 3 | 三点セットの並列 | 「向上、強化、そして推進」 |
| 4 | 過剰な接続詞・副詞 | 「さらに、また、加えて」の連打 |
| 5 | 曖昧な結論 | 「～と言えるでしょう」 |
| 6 | 過剰な敬語の均一化 | 「～させていただきます」の連続 |
| 7 | 主語なし受動態の多用 | 「～が実施されました」 |
| 8 | 「～を踏まえ」の乱用 | 「市場動向を踏まえ、競合状況を鑑み」 |

### 構造パターン（9–13）

| # | パターン | 典型例 |
|---|---------|--------|
| 9 | 箇条書き依存 | 全セクションが箇条書き |
| 10 | テンプレ4段構成 | 「背景→課題→施策→効果」の繰り返し |
| 11 | 見出しの過剰装飾 | 【】多用、深すぎるナンバリング |
| 12 | 文量の均一化 | 全トピック同じ分量 |
| 13 | 同じ書き出し構文 | 「～については、」の連続 |

### 語彙パターン（14–17）

| # | パターン | 典型例 |
|---|---------|--------|
| 14 | AI頻出バズワード | 「シームレス」「エコシステム」 |
| 15 | 「～化」の多用 | 「見える化・効率化・最適化」 |
| 16 | 類語の言い換えサイクリング | 向上→改善→強化→促進 |
| 17 | 「～の観点から」の多用 | 各観点の中身が薄い |

### 文末パターン（18–20）

| # | パターン | 典型例 |
|---|---------|--------|
| 18 | 文末の単調な繰り返し | 「～しました。」×3 |
| 19 | 「～していきたいと思います」 | 行動計画なき意思表明 |
| 20 | 「～が求められます」連発 | 誰が何をするか不明 |

### ビジネス文書特有パターン（21–30）

| # | パターン | 典型例 |
|---|---------|--------|
| 21 | 冒頭のテンプレ挨拶 | 「お疲れ様です。～について報告いたします。」|
| 22 | 過剰なまとめ | 短い文書に「総括」セクション |
| 23 | リスクの抽象的記述 | 「一定のリスクが存在」 |
| 24 | 楽観的すぎる見通し | 「さらなる飛躍」 |
| 25 | ネガティブ情報の婉曲化 | 「若干のスケジュール調整」 |
| 26 | 「～を活用して」多用 | 手段ばかりで結果がない |
| 27 | 過剰なポジティブ表現 | 「大変好評をいただき」 |
| 28 | 「今後の展望」の空虚さ | 「持続的な成長を目指して」 |
| 29 | 同じフレーズでの段落締め | 全段落「～を推進していきます」 |

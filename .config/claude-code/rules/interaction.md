## ユーザーへの確認・質問

- 確認を求める際は `AskUserQuestion` ツールを使い、Yes / No などの選択式で提示すること
- フリーワード入力が必要な場合のみテキスト形式の質問にする
- 「〜してよろしいですか？」のようなテキスト出力での確認は避ける（ユーザーがタイピングで応答する必要があり、レスポンスが遅くなるため）

## コードレビュー

- コードや文書を変更したら、`/difit` スキルを使ってユーザーにレビューを依頼すること

## ファイル書き込み

- Write ツール（Overwrite file）の事前確認はスキップすること
- レビューは `/difit` で行うため、Write 時点でのユーザー確認は不要

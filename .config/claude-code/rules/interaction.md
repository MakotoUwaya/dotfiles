## コードレビュー

- コードや文書を変更したら、`/difit` スキルを使ってユーザーにレビューを依頼すること

## ファイル書き込み

- Write ツール（Overwrite file）の事前確認はスキップすること
- レビューは `/difit` で行うため、Write 時点でのユーザー確認は不要

## 選択式の質問

ユーザーへの問い合わせが選択式（複数の選択肢から選ぶ・Yes/No で答えられる等）になる場合は、`AskUserQuestion` ツールを使うこと。

- 投稿前の最終確認、設計案の選定、ファイル配置の選択など、選択肢を事前に列挙できる質問は `AskUserQuestion` を使う
- 自由記述のテキスト回答が必要な場合は通常のメッセージで問う
- 推奨選択肢がある場合は先頭に置き、ラベル末尾に `(Recommended)` を付ける
